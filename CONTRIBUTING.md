# Contributing

Contributions are welcome!

## Adding a New Skill

1. Create a new folder in `skills/`
2. Add a `SKILL.md` file with YAML frontmatter
3. Include references in a `references/` subfolder if needed

## Skill Format

```yaml
---
name: skill-name
description: When to use this skill
metadata:
  version: 1.0.0
---
```
